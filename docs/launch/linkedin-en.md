Sharing World Radio App — my web app for listening to radio from around the world 🌍🎧

A big part of the work was keeping playback continuous while browsing stations, changing languages and moving between views. I also focused on a compact mobile layout and a personal library that works without an account.

What you can do:
• discover stations through Radio Browser and add them to your library,
• arrange favorites, revisit listening history and set a sleep timer,
• share stations and transfer your library through JSON backups,
• choose light, dark or system appearance and one of 8 interface languages,
• install it as a PWA and open your saved library offline — live radio still needs an internet connection.

Built with React 19, Vite, styled-components, Context API and Netlify Functions. Unit and browser checks cover playback, accessibility, mobile layouts and offline behavior.
